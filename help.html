1. Introduction

What SAIP Does

SAIP (Software Asset Intelligence Platform) is a desktop application designed for software asset managers. It takes the messy, inconsistent software inventory data that comes out of tools like MECM, Intune, and Tanium and transforms it into clean, normalized data you can actually use.

The core problem SAIP solves: your inventory tools report software names exactly as vendors registered them — "Microsoft 365 Apps for enterprise - en-us", "Microsoft Office 365 ProPlus", and "M365 Apps Enterprise" might all be the same product. SAIP recognizes these variations, maps them to a single canonical product, calculates your license demand, handles suite suppression, and exports clean reports.

Who It Is For

  • Software Asset Managers responsible for license compliance
  • IT Asset Management teams running true-up or audit preparations
  • Consultants performing license optimization engagements
  • Procurement teams who need accurate demand data before renewals

Key Concepts

Normalization — The process of taking raw software strings and mapping them to a canonical product name. This is the core function of SAIP.

License Position — A summary showing how many licenses you need for each product, calculated by counting unique users or devices.

Suite Suppression — When a user has both a suite (like Microsoft 365 E3) and a product included in that suite (like Teams), the individual product is marked as "suppressed" to prevent double-counting.

Exclusions — Patterns that filter out non-licensable software: drivers, runtime libraries, Windows updates, and other noise.

How Data Stays on Your Machine

SAIP is a local desktop application. Your data never leaves your computer. There are no cloud services, no telemetry, and no internet connection required. All processing happens locally, and all project data is stored in SQLite database files on your machine.

2. Getting Started

System Requirements

  • Operating System: Windows 10 or Windows 11
  • RAM: 4 GB minimum, 8 GB recommended for large datasets
  • Disk Space: 200 MB for the application, plus space for project data

  3. Accept the license agreement

When you first open SAIP, you'll see the Home screen with an empty project list. The application is ready to use immediately — no additional configuration or account setup is required.

3. Loading Your Data

Supported File Formats

SAIP accepts CSV (comma-separated values) and XLSX (Excel workbook) files. Files should contain at minimum a column for the software name.

Exporting from MECM / SCCM

Run the following SQL query against your MECM database:

SELECT
  sys.Name0 AS ComputerName,
  sys.User_Name0 AS UserName,
  arp.DisplayName0 AS SoftwareName,
  arp.Publisher0 AS Publisher,
  arp.Version0 AS Version,
  arp.InstallDate0 AS InstallDate
FROM v_GS_ADD_REMOVE_PROGRAMS_64 arp
JOIN v_R_System sys ON arp.ResourceID = sys.ResourceID
ORDER BY sys.Name0, arp.DisplayName0

Export the results to CSV or save as Excel. For 32-bit programs, use v_GS_ADD_REMOVE_PROGRAMS instead, or union both views (see Section 14).

Exporting from Intune

In the Microsoft Intune admin center, navigate to Apps > Monitor > Discovered apps and click Export. SAIP's column profiles automatically recognize Intune export column names.

Exporting from Tanium

In the Tanium Console, navigate to Asset > Software Inventory, apply your filters, click Export and choose CSV format.

Generic CSV Format

ColumnDescriptionRequired
ComputerNameThe device/hostnameRecommended
UserNameThe logged-in userRecommended
SoftwareNameThe raw software titleRequired
PublisherThe software publisherOptional
VersionThe installed versionOptional
InstallDateDate of installationOptional

Mapping Your Columns

After importing a file, SAIP presents the Column Mapping screen. SAIP auto-detects common column names. Review the auto-mapped columns, correct any errors, and at minimum map the Software Name column.

Column Profiles

SAIP ships with built-in column profiles for MECM, Intune, Tanium, and ServiceNow. These profiles contain the known column header names, allowing auto-detection of your source system.

4. Running Normalization

What Happens During Normalization

When you click Run Normalization, SAIP processes every raw software string through a multi-stage matching pipeline:

  1. Customer Exclusions are checked first
  2. Platform Exclusions are checked next
  3. Customer Overrides are applied
  4. Platform Mappings are checked
  5. Fuzzy Matching attempts to match remaining items
  6. Unmapped items are flagged for manual review

Matching Priority

PrioritySourceConfidence Score
1Customer Exclusions0.98
2Platform Exclusions0.93
3Customer Overrides1.00
4Platform Mappings0.95
5Fuzzy MatchVariable (0.01–0.89)
6Unmapped0.00

Confidence Scores

  • 1.00 — Customer override (you manually mapped this)
  • 0.95 — Platform knowledge base match
  • 0.93–0.98 — Exclusion rule match
  • 0.50–0.89 — Fuzzy match (higher = better similarity)
  • 0.00 — No match found (unmapped)

Summary Cards

  • Total Records — Raw software rows processed
  • Matched — Items mapped to a canonical product (green)
  • Needs Review — Fuzzy matches below threshold (amber)
  • Unmapped — No match found (red)
  • Excluded — Filtered by exclusion rules (gray)
  • Match Rate — Percentage of non-excluded items matched

What to Do After Normalization

  1. Check the Match Rate — aim for 85%+ on a clean dataset
  2. Review the Needs Review tab for fuzzy suggestions
  3. Check the Unmapped tab for items needing overrides
  4. Verify the Excluded tab for false positives
  5. Move to the License Position tab

5. Understanding Your Results

Approved Items

Items in the Normalized tab have been matched with high confidence. Each row shows the original raw string, matched canonical product, confidence score, publisher, and license type.

Needs Review Items

The Needs Review tab contains fuzzy matches SAIP isn't fully confident about. Each shows the original string, suggested product, confidence score, an Approve button, and a Map to... option.

Unmapped Items

The Unmapped tab shows strings SAIP couldn't match. You can create an override, add an exclusion, or skip for later.

Excluded Items

Items filtered by exclusion rules — typically drivers, runtimes, Windows updates, and firmware. Exclusions are non-destructive: excluded items remain in your data for audit purposes.

Suppressed Items (Suite Children)

Items with suppressed_flag = True appear in results but are excluded from license demand counts. These are products covered by a suite license the same user or device has. For example, if user "jsmith" has both Microsoft 365 E3 and Microsoft Teams, Teams is suppressed because E3 covers it.

6. License Position

How Demand Is Calculated

License TypeCalculationExample
per_userCount distinct usernames50 users with Excel = demand of 50
per_deviceCount distinct device names30 devices with AutoCAD = demand of 30
per_installCount all installation rows75 installs = demand of 75
freeAlways zeroVLC Media Player = demand of 0

Per-User vs Per-Device

Per-user: one license per unique person, regardless of how many devices. If "jsmith" has Office on laptop and desktop, that's 1 license.

Per-device: one license per unique device, regardless of how many people use it. A shared workstation needs 1 license even if 5 people log in.

Suite Suppression Examples

Microsoft 365 E3

User "jsmith" has: M365 E3, Teams, Word, Excel. M365 E3 covers all three. Result: Only M365 E3 counts. Teams, Word, and Excel are marked suppressed.

Adobe Creative Cloud All Apps

User "adesigner" has: CC All Apps, Photoshop, Illustrator. CC All Apps covers both. Result: Only CC All Apps counts. Photoshop and Illustrator are suppressed.

License Status Bar

  • Green — Demand within entitlement
  • Amber — Approaching limit (80%+)
  • Red — Overage (demand exceeds entitlement)

Entering Cost Data

Click a product row, enter the unit cost and entitlement count. SAIP calculates total cost and shows under/over-licensed status.

Coverage Indicator

  • 100%+ — Sufficient licenses
  • 80–99% — Close to limit
  • Below 80% — Significantly under-licensed

What Overage Means

Overage means demand exceeds entitlement. This is a compliance risk. The overage count tells you exactly how many additional licenses to purchase.

7. Managing Overrides and Exclusions

Adding a Customer Override

  1. Navigate to the Overrides & Exclusions tab
  2. Click + Add Override
  3. Enter the raw string pattern
  4. Select the target canonical product
  5. Choose the match type
  6. Click Save

Adding a Customer Exclusion

  1. Navigate to the Overrides & Exclusions tab
  2. Click + Add Exclusion
  3. Enter the pattern
  4. Choose the match type
  5. Click Save

Match Types

Match TypeBehaviorExample
exactMust match full string exactly"Notepad++" matches only "Notepad++"
startswithString begins with the pattern"Microsoft Visual C++" matches versioned variants
containsPattern appears anywhere in the string"Runtime" matches "Java SE Runtime Environment"
regexRegular expression match^Adobe\s+Photoshop\s+\d+ matches versioned Photoshop

When to Use Overrides vs Exclusions

  • Override: Software is licensable but SAIP mapped it incorrectly or couldn't map it
  • Exclusion: Software is not licensable (internal tools, drivers, OS components)

Bulk Actions

Select multiple items with checkboxes, then click Bulk Map or Bulk Exclude.

12. Troubleshooting

File Won't Import

  • Check format: only .csv and .xlsx accepted
  • Save CSV as UTF-8 encoding
  • File must have at least a header row and one data row
  • Ensure the file isn't locked by another application
  • Large files (500K+ rows) may take several minutes

Match Rate Is Very Low

  • Verify the Software Name column is mapped correctly
  • Check data quality: truncated or encoded strings reduce matches
  • Add customer overrides for common unmapped items
  • Verify legitimate software isn't being excluded

All Items Showing as Unmapped

The Software Name column is likely not mapped correctly. Go back to Column Mapping and verify.

License Position Seems Wrong

  • Check license types (per_user vs per_device)
  • Suite suppression may be correctly reducing demand
  • Look for duplicate records (32-bit + 64-bit entries)
  • Verify user/device data columns aren't empty

PDF Export Not Working

  • Check disk space
  • Avoid special characters in the export path
  • Try exporting to your Desktop
  • Restart SAIP if the issue persists

Common MECM Export Issues

  • Include v_GS_ADD_REMOVE_PROGRAMS (without _64) for 32-bit apps
  • MECM inventory may be up to 7 days old
  • MECM sometimes reports both per-user and per-machine installs
  • Null usernames affect per-user license calculations

13. Frequently Asked Questions

Is my data sent anywhere?

No. SAIP is fully local. No cloud services, no telemetry, no analytics.

Can I use SAIP offline?

Yes. The only feature requiring internet is downloading intelligence updates.

How often should I run normalization?

Whenever you import new data or change overrides/exclusions. Monthly cadence works well for ongoing engagements.

What is a canonical product?

The standardized, authoritative name for a software product. Multiple raw strings can map to a single canonical product.

Why is Photoshop showing as suppressed?

Because the same user or device also has Adobe Creative Cloud All Apps, which includes Photoshop. This prevents double-counting.

Why are drivers and runtimes excluded?

They are not commercially licensable software. Including them would inflate your data with noise.

How do I handle products not in the knowledge base?

Create a customer override, or contact DataForge Systems to request its addition in the next intelligence update.

What is the difference between Professional and Business licenses?

This depends on the vendor. SAIP tracks them as separate canonical products with separate demand counts.

How do I get the intelligence subscription?

Visit dataforgesystems.io or contact your DataForge Systems account representative.

How do I update to a new version?

Download the latest installer from your DataForge Systems account and run it. Your project data is preserved.

14. MECM SQL Query Reference

Standard Query (64-bit)

SELECT
  sys.Name0 AS ComputerName,
  sys.User_Name0 AS UserName,
  arp.DisplayName0 AS SoftwareName,
  arp.Publisher0 AS Publisher,
  arp.Version0 AS Version,
  arp.InstallDate0 AS InstallDate
FROM v_GS_ADD_REMOVE_PROGRAMS_64 arp
JOIN v_R_System sys ON arp.ResourceID = sys.ResourceID
ORDER BY sys.Name0, arp.DisplayName0

Combined 32-bit and 64-bit Query

SELECT
  sys.Name0 AS ComputerName,
  sys.User_Name0 AS UserName,
  arp.DisplayName0 AS SoftwareName,
  arp.Publisher0 AS Publisher,
  arp.Version0 AS Version,
  arp.InstallDate0 AS InstallDate
FROM v_GS_ADD_REMOVE_PROGRAMS_64 arp
JOIN v_R_System sys ON arp.ResourceID = sys.ResourceID

UNION ALL

SELECT
  sys.Name0 AS ComputerName,
  sys.User_Name0 AS UserName,
  arp.DisplayName0 AS SoftwareName,
  arp.Publisher0 AS Publisher,
  arp.Version0 AS Version,
  arp.InstallDate0 AS InstallDate
FROM v_GS_ADD_REMOVE_PROGRAMS arp
JOIN v_R_System sys ON arp.ResourceID = sys.ResourceID

ORDER BY ComputerName, SoftwareName

Filtering by Collection

SELECT
  sys.Name0 AS ComputerName,
  sys.User_Name0 AS UserName,
  arp.DisplayName0 AS SoftwareName,
  arp.Publisher0 AS Publisher,
  arp.Version0 AS Version,
  arp.InstallDate0 AS InstallDate
FROM v_GS_ADD_REMOVE_PROGRAMS_64 arp
JOIN v_R_System sys ON arp.ResourceID = sys.ResourceID
JOIN v_FullCollectionMembership fcm
  ON sys.ResourceID = fcm.ResourceID
WHERE fcm.CollectionID = 'SMS00001'  -- Replace with your collection ID
ORDER BY sys.Name0, arp.DisplayName0
