Workflow

From raw export to
license position in five steps

01
Load sources
Import CSV or XLSX exports from MECM, Intune, Tanium, or any discovery tool. Multiple sources per project.
02
Map columns
Select software name, device, and user columns. MECM and Intune formats are auto-detected from headers.
03
Normalize
Engine excludes noise, matches canonical products, suppresses suite children, assigns confidence scores.
04
Review position
Demand quantities, owned vs in-use, financial exposure, and overage risk per product in one view.
05
Export
Formatted Excel workbook, flat CSV for Power BI, or JSON. Timestamped and audit-ready.
Capabilities

Built for real
SAM engagements

Every capability in SAIP exists because real SAM work demanded it. No demos-only features. Everything ships in the base product and works fully offline.

🔬
Deterministic normalization
Six-level matching priority with explainable confidence scores. Every result is traceable to its source — customer override, platform mapping, or fuzzy match.
🧩
Suite suppression engine
Adobe CC covers Photoshop. M365 covers Teams. Suite children are suppressed per user — never counted twice in your license demand. Per-user aware, not global.
📊
License position calculation
Per-user products count distinct usernames. Per-device products count distinct hostnames. Demand quantities reflect your real obligation — not raw install counts.
🚫
First-class exclusions
Drivers, VC++ redistributables, .NET runtimes, KB patches, OEM utilities, and update agents are identified and removed before normalization runs.
💰
Cost and exposure tracking
Enter contract values, renewal dates, and owned quantities. View coverage status, shortfall risk, and total portfolio spend before you export.
🏢
Multi-source deduplication
Import from MECM, Intune, and Tanium in the same project. Duplicate records across sources are automatically deduplicated — one device, one count, regardless of how many tools reported it.
🖥️
Duplicate device detection
Automatically detects when the same device appears under different name formats — PC-CORP-001, pc-corp-001, PC-Corp-001. Preview affected rows before merging to see the exact license impact.
🔒
Fully offline
Your inventory data never leaves your machine. No cloud upload, no SaaS account, no DPA required. Installs and runs in air-gapped and government environments.
📥
Power BI-ready exports
Formatted Excel workbook with five tabs, flat CSV with canonical field names, and structured JSON. All exports are timestamped and audit-ready.
🤖
Intelligence subscription
Monthly KB JSON updates with new product mappings, naming variants, exclusion patterns, and suite rules sourced from live IT community data. Import in seconds — no reinstall needed.
⚡
Same-day KB updates
Report an unmapped product and we research it the same day. New naming variants are added to the next intelligence update — often within hours. No other SAM tool can match that turnaround.
📈
Run comparison
Compare normalization runs side by side to track improvements over time. See exactly what changed between your last import and today's data.

Why we built this

Built by a practitioner.
Not a software company.

DataForge Systems was founded by a software asset management professional with over a decade of experience managing software inventory for a large government organization.

In that time, one problem never got solved: nobody could take the raw, messy data that discovery tools produce and turn it into something a SAM team could actually trust. Every normalization effort ended up in a spreadsheet, maintained manually, drifting further from reality with every software update and every new device.

SAIP exists because that problem deserved a real solution — one built by someone who has lived it, not by a software team guessing at what SAM managers need.

Every feature in SAIP — the exclusions engine, the suite suppression logic, the per-user vs per-device calculation, the MECM query reference — came directly from real problems encountered in real engagements. Nothing is theoretical. Everything is tested against the kind of data that actually comes out of enterprise environments.
